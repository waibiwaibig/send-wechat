# send-wechat 0.1.0-rc.1

This is the first public release candidate for cross-platform manual
acceptance. It is not the npm `latest` release.

## Included

- one-command owner-controlled Cloudflare personal Relay provisioning;
- QR binding to one Weixin user and one-time connection confirmation;
- text, stdin, and file sending through one owner-scoped Hub;
- encrypted live remote-device pairing without a public project service;
- native per-user credential and background-service adapters for macOS,
  Windows, and GNU/Linux;
- fail-closed 24-hour session handling, local idempotency, and redacted audit
  metadata.

## Verified

- the full automated suite, Worker runtime harness, package build, dependency
  audit, and isolated tarball installation;
- a real macOS arm64 Hub installation, user-owned Cloudflare deployment,
  Weixin QR login, inbound activation, and text delivery on 2026-08-24.

## Still required before 0.1.0

- native Windows and GNU/Linux installation, credential-store, and service
  acceptance;
- real remote-device text/file delivery, invitation replay rejection, and Hub
  offline behavior;
- remaining file, expiry, reset, uninstall, and reboot checks documented in
  `docs/manual-acceptance.md`.

Windows/WSL mixed operation is not supported.
