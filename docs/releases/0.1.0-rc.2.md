# send-wechat 0.1.0-rc.2

This release candidate makes the repository's onboarding contract Agent-first.
It remains a prerelease until the manual platform matrix is complete.

## Included

- a README and packaged skill that tell an authorized Agent to perform safe
  installation, diagnostics, QR presentation, recovery, and SSH setup;
- a fresh Hub setup that reaches ready without creating a device invitation;
- short-lived invitations created only by the Agent's direct pairing pipeline;
- stdin-only remote pairing, with the removed invitation-argv interface;
- WSL and headless GNU/Linux as remote clients without Secret Service or a
  systemd user service;
- a strict Linux client credential file with owner-only directory and file
  permissions, atomic writes, and fail-closed schema checks.

## Verification boundary

Automated tests cover the CLI seams, setup state transitions, credential-file
policy, headless path handling, reset behavior, package build, and Worker
runtime. Real Cloudflare authorization, Weixin QR/inbound activation, SSH
pairing, native Windows/GNU/Linux Hub services, and real message/file receipt
remain the manual acceptance gates in `docs/manual-acceptance.md`.
